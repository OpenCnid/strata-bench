Start with the current Windows development environment and Mineflayer on vanilla 1.19.2, then immediately test one pinned Enigmatica 9 Expert/Forge distribution. Preserve official CurseForge acquisition and server artifacts; Mineflayer is a protocol client and does not load Forge Java mods. Test the exact handshake/channels, modded registries/metadata, safe navigation, an expert-altered recipe, a container and a working modded machine. A join or vanilla action inside the pack is insufficient. Resolve exact gaps with tested extensions or a separately qualified structured Forge client backend; retain backend-specific support identities. E6E/E2E are later compatibility modules, not a difficulty order.

Use Python 3.12/asyncio/Pydantic 2 for the controller, Typer CLI and FastAPI for worker/operator services; Node.js active LTS/TypeScript Mineflayer backend with pinned pathfinder/protocol/data/plugins; Java/Gradle private telemetry and conditional Forge client/settings extensions; versioned JSON schemas with authenticated IPC/HTTP/WebSocket; optional MCP facade for agent hosts. Start with one durable SQLite controller and append-only JSONL/content-addressed local evidence. Use Parquet/DuckDB for analysis and FFmpeg for bounded recordings. PostgreSQL, object storage, distributed scheduling, and an interactive dashboard are later needs-driven additions. Exact dependencies/toolchains must be locked during implementation.

Keep Codex's native agent loop and selected Dovetail plugin. Implement AgentRuntimeAdapter first over pinned `codex exec --json`; game interaction uses native command execution of `mcgame`, returning bounded JSON from a persistent Mineflayer worker. Do not launch a new bot per tool call or invent live prompt injection into a running CLI. Prove actual plugin/helper capability, JSONL event/usage accounting, interruption, scoped command execution and session resume/fresh handoff against the installed CLI. Missing helper/accounting isolation blocks the full configuration. Optional MCP or app-server can implement the same seams later; neither is required initially. Record the host/bridge revisions as system identity. Each agent has separate workspace, credentials/capabilities, artifacts and budget; one executor owns its avatar.

Primary game track: `structured-actions/v1`, Mineflayer first, one isolated backend worker and executor per avatar. Proposed GameBackend contract covers connect, capabilities, observe/events, execute/status/cancel/stop-all, checkpoint/restore and health. Publish compact structured player position/health/inventory, open-container slots, scoped chat and bounded observed nearby blocks/entities. Do not expose hidden chunk contents/ore, unopened inventories, private server state or evaluator events. Pathfinding uses the same allowed observed map, with unknown cells conservative; clear backend caches for fresh probes. Event summaries on action completion, state changes and damage avoid an inference call every tick; images are an optional declared extension.

Allow bounded navigate/look/dig/place/equip/use/interact/slot/single-recipe-craft/chat actions. The fixed local motor controller handles execution between model decisions. Disable automatic digging/building/resource gathering during navigation and implicit combat/eating plugins. No built-in recursive recipe planner, hidden quest solver, raw bot/packet/JS eval, teleport or direct inventory/machine mutation. Pack-correct recipe/quest information requires a tested player-accessible projection. Use namespaced registry IDs and typed unsupported errors; no guessed vanilla substitutes. Pin tools, motor routines, filters and backend versions across comparisons.

Actions carry observation/revision/lease/epoch/deadline/preconditions, asynchronous accepted/executing/completed/failed/cancelled/unknown receipts and fresh resulting state. One mutation lane per avatar; explicit cancel/stop halts local pathfinding/dig/use and releases controls without LLM intervention. Bound movement to a proposed 30 s and ordinary actions to 10 s; no infinite automation. Unknown effects require resync, not blind retry. Account for local execution events/ticks, not merely the high-level request count. Optional pixel/OS profiles and richer assistance remain separate conditions.

Separate operator/evaluator and gameplay authority. The private evaluator gets authoritative server events, hidden scoring, holdouts, and campaign administration. Gameplay agents get only their permitted observations, own artifacts, declared communication, and documentation. No server filesystem/admin commands, hidden scores, private fixtures, sibling experiments, or evaluator endpoints. Do not put the spec, research docs, scoring names, or hidden objective in the agent workspace. Prompt-only secrecy is insufficient; define actual filesystem/process/network capability isolation and leak tests. Non-disclosure cannot guarantee the model never guesses the research purpose.

Default to natural, unmodified pack play. Hidden measurement criteria are required; secret mechanic alterations are an optional separate diagnostic track. Allow normal recipe/quest interfaces under an explicit information policy. Default external knowledge to a pinned permitted corpus; log open-web use in a separate condition. Own inventory is part of the primary structured profile; unopened inventories, hidden quest data and unfiltered recipe/dependency dumps are excluded.

Separate authentic persistent campaigns from controlled held-out evaluation clones. At fixed exposure checkpoints, test learned-memory/skill clones versus initial-state clones with identical fresh conversations, game state, equipment, world fixtures, tools, and probe budgets. Discard probe state afterward. This distinguishes experience benefits from accumulating gear, machines, or terrain knowledge. Include learning curves, retention, transfer, absolute success, time-to-milestone with censoring, and aggregate cost. Do not equate progress with adaptation. Pin base weights within a cohort; future model releases get fresh cohorts and optional separately labeled inherited-artifact arms.

Match experienced/fresh probes on the same instance, then discard both probe processes. Repeated checkpoint evaluation must not expose earlier test instances to learning or permit tuning on sealed results.

If a provider generation change is detected, end the fixed-model segment, quarantine observations after the last verified identity boundary, and start a new cohort with fresh anchor controls. Include frozen-persistence, frozen-skill, and no-self-play controls as budget permits; define exactly which artifacts and context survive. Separate Mineflayer workers need independent identities/sockets and action/state routing; optional rendered backends additionally need tested display/input isolation.

Transfer memory into fresh pack worlds rather than upgrading incompatible world saves.

Design leases, heartbeats, sequence/epoch IDs, bounded actions, cancel/stop-all watchdog, ambiguous-ack recovery, and consistent checkpoint sets covering world/player/quest/team files plus backend caches/state, applicable keymaps, agent state and skill revisions. Start with clean-stop snapshots. Input retries must not duplicate an effect; infrastructure rollback cannot silently erase cost or preserve unfair future knowledge. Death and bad decisions are gameplay outcomes. Define infrastructure, policy, and invalid-evaluation failure categories.

Plan a `minecraft-keybindings` skill: discover -> diagnose -> allocate -> apply transaction -> verify actual in-game effects and competing bindings -> persist/restart-check -> rollback. Preserve essential controls, handle unknown/custom mods conservatively, distinguish text from gameplay input, and permit only a tested key pool. Give specific tests for conflict/no-conflict, unsupported keys, legacy backend, GUI/game contexts, held-key timeout, restart persistence, and cross-client isolation.

Use backend and capability/policy digests in system identity, CampaignConfig, Observation, actions and checkpoint state. Primary observations require structured payloads; image/keymap fields are nullable unless their capabilities are present. Preserve the ActionBatch record name but let structured v1 contain one typed bounded action; raw events are conditional on physical-input profiles. Full hotkey repair and persistence remain T05/G1 work on a qualified extension; the initial vanilla/backend slice must not be blocked by pretending Mineflayer has physical key mappings. Optional physical-input profiles retain ordinary-input and OS parity tests.

The game CLI is a transport adapter, not unrestricted Node code execution. ACL/process-scoped IPC must reject cross-agent callers, private endpoints, unknown actions and stale leases regardless of shell permissions. Long actions return IDs; status/wait/cancel are bounded. The same typed contracts can later be exposed as MCP without changing agent permissions.
