protocol using the native `functions.exec` JavaScript environment already under

or tool. Select an active revision's `active/<skill>/scripts/*.js` file; bind exact
UTF-8 bytes to its CAS reference. Only the previously registered native read call
can supply its returned path/ref/text. An echoed provider argument, another
participant's read, unregistered return or changed bytes cannot issue the script.
The fixture copies those bytes unchanged into a fresh native exec call once per
participant. Returned completion must be a native content frame with the exact
echoed issued source/call and correct participant. Scalar notification text,
changed source/results, missing echoes and yielded cells cannot become success.

native identity/activation fixture. Each participant gets one additional charged
turn between initial artifact reads and the unchanged helper protocol. The

with the existing nine-request parent bound, four-request helper reservation and

instructions explicitly describe this selected JavaScript path; their changed
bytes enter the normal frozen profile. Other languages and host execution remain
unsupported. Activation/publication alone still grants no execution authority.

This is **implemented but unverified in the actual selected runtime**. The fixture
report deliberately leaves broker-effect and runtime qualification false. A
successful exec alone cannot certify action effects, source-bound publication,
