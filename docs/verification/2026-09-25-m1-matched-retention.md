## Common protocol

[Matched fixture](../../tools/native_matched_retention_probe.py) and explicit
[native runner mode](../../tools/native_mcp_identity_probe.py) preregister full
and frozen-persistence arms before any source job. Both start with equivalent
public artifacts, world, configuration, allowance and consumed costs through
a recovery checkpoint. Recovery permits within-episode learning in both arms.
The same prompt, reads, writes, publication program, helper limit and request
ceiling run in both arms; phase two reverses first-phase arm order. Opaque
native paths do not name the arm. Arm labels remain operator-only.

Both participants read admitted active files and attempt forbidden immutable
writes. The root writes notes, handoff and a complete executable candidate;
a clean helper cannot read root history. A normal episode checkpoint must
retain these in full and discard them in frozen-persistence. A new native
episode must demonstrate the actual retained/reset surface and fresh private
state while retaining all costs. This does not execute the candidate script
or qualify every runtime cache/session category.
