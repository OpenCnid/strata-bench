## Missing dependency and implementation

equality. It neither resolves those artifact references to a committed native
checkpoint nor proves their origins. Keep its historical synthetic scope;
do not use it alone as probe admission.

The private [projection reader](../../evaluator/src/strata_evaluator/native_probe_projection.py)
adds `NativeProbeArtifactSelection/1` and `NativeProbeArtifactProjection/1`
under `native-checkpoint-probe-artifact-projection/1`. An operator/evaluator
selects exact initial paths, retained note/handoff paths and active skill names
from one named committed skill set. The reader reconstructs the complete native
checkpoint/export/revision evidence and derives content references itself.
It accepts no supplied origin labels, raw substitute file references, t=0
assertions or launch authority. It records actual/scheduled checkpoint exposure.

The common initial surface comes from the registered baseline; all initial
procedure paths are mandatory. Retained files must be actual checkpoint notes
or handoff. Learned procedures/scripts must be active, source-bound campaign
revisions; drafts/publication manifests and helper-private results are not
selected. Evaluation-account sources refuse even for plain notes with no skill
publication. Full and no-self-play allow selected retained artifacts;
frozen-persistence projects initial artifacts only even from a recovery
checkpoint; frozen-skills requires its versioned classifier and no learned
skill selection. The final union is rechecked for case/path aliases, byte
integrity, forbidden state paths and aggregate quotas.

Schema exports remain evaluator-only; the operator schema-build tool loads the
separate evaluator package explicitly. No public tool, broker catalog, runtime
bootstrap or canonical record count changes. Gameplay principals cannot invoke
this private service. The result includes private source references and must
never be supplied wholesale to a gameplay root/helper.

This is an artifact-provenance input to the forthcoming clone builder. Null
session/cache fields mean those objects are excluded from this projection;
they do not prove an actual runtime reset. Explicit path selection still needs
the protocol's content/corpus review: filenames cannot detect private data or
personal keymaps encoded in prose. The complete pre-start manifest must also
