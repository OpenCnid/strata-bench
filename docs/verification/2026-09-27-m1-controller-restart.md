## Ownership and recovery

The private WorkerRestartGrant/2 adds the digest of the actual repair grant.
Controller admission requires that exact worker capability and matching
campaign/avatar/epoch/lease. Older /1 grants remain historical development
evidence and cannot authorize this controller route. Strict reply validation
joins checkpoint, original connection, confirmed old-terminal proof, replacement
process/connection, scope, guardian profile and false resume/admission flags.
No operation is added to the gameplay capability catalog.

NativeRepairRestart records one immutable prepare request against the complete
pending native head and confirmed apply. Its durable states are PREPARING,
PREPARED, DETACHING, DETACHED, ATTACHING and ADOPTED. Each mutation has a durable
intent before dispatch; an interrupted or uncertain intent permits only status
reconciliation. It cannot silently resend prepare, detach or attach. A crash
before actual dispatch can therefore require recovery instead of guessing that
the operation is safe to replay. Original wall/monotonic expiry and reservation
remain applicable throughout.

Adoption requires the exact recorded replacement paths and descriptor, same
target/settings identity, a new native session, worker stop/replacement evidence,
current guardian implementation digest, exact continued native checkpoint,
retained repair holds and the complete expected runtime/persistent keymap.
Publish the private witness before committing ADOPTED. The original native
admission and its descriptor digest remain unchanged; the new adoption row is
the explicit successor. Pending adoption blocks ordinary native writes.
After adoption, native commit/rollback accept only the replacement descriptor.
Neither adoption nor settings commit releases the worker/controller input hold.

Client creation is still performed by the test fixture. Controller-owned real
launcher orchestration, qualified control projection, authentic verification,
complete consumption/settlement and explicit controller/worker/native/guardian
resume remain unfinished. This route is not an authentic same-server/team
