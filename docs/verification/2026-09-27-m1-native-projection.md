## Change

`src/mcbench/native_settings_projection.py` consumes a pinned private
NativeSettingsQualification/1 and exact profile-bound reports. Required reports
cover atomic CAS, persistence/restart, essential controls, settings isolation
and full binding metadata. Separate reports bind owner identity, each tested
consumer and every physical pool key. Reports are operator-issued conformance
evidence, not generated by this reader. Qualification fails before native reads
when evidence is absent, expired, changed, foreign or only an example.

Every source is bounded and SHA-256 checked; the complete read has a4MiB budget.
The native settings snapshot is bracketed by body/connection identity reads.
The complete binding set, translation, native mutability, runtime value and
persisted value must match. Canonical keyboard/scancode/mouse encodings are
decoded without pretending numeric values are portable. Actual revision/key
values change with the client; qualification and metadata remain in the policy
digest. The native supported=false diagnostic is not rewritten.

The projection is a controller reader only. Generic writes, automatic restart
and stop-all refuse; all writes remain on NativeRepairFlow. A replacement reader
is constructed only after the controller adopts the guarded replacement, using
the same qualification. No new gameplay tool, credential route, input motor,
public capability, accounting settlement or resume operation is introduced.
